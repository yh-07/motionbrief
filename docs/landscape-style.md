# 横屏（16:9）卡通科普风格

- 依据：`work/style_research/youtube_toon_survey.md`（15 个 YouTube 样本）与 `work/style_research/bilibili_survey.md`（15 个 B 站样本）。
- 证据只来自标题、元数据和缩略图；没有看过视频本身，所以节奏和转场只是假设。

## 已落地到引擎的部分

| 要素 | 来源 | 实现 |
|---|---|---|
| 深色底 + 高饱和强调色 | 观察到（两边缩略图） | 沿用现有 `Cartoon Tech v2` 的背景和色板，不改 |
| 底部黄色字幕条 | 观察到（YouTube 样本） | `motion/tokens.json` 的 `typography.subtitleLandscape`，仅 16:9 生效 |
| 章节卡 | 推断（B 站系列标题"第一季""全 N 集"） | `Scene.chapter` + `Video.chapterCards`，默认 16:9 开、9:16 关，显示 2.5 秒 |
| 8–15 分钟时长 | 观察到（B 站成人科普元数据，中位数约 12 分钟） | `longform` 档位（480–900 秒） |
| 多个对象各占一列 | 设计决定（非调研结论） | `render/svg_canvas/scene.py` 的 `_object_slots`，竖屏组件按高度缩放放入列中 |

## 未落地（需要人工看样片后再定）

- 大写粗体标题 + 投影、描边或霓虹发光：调研里只在缩略图中看到，没有对应的文字样式 token，本期不做。
- 形状擦除式转场：只有一张缩略图的单帧证据，本期不做。
- 每 3–5 秒切镜：推断，目前的分镜节奏由分镜提示词和 `maxVisualGapSec` 约束，没有为横屏单独调整。
- 角色风格（大头、圆润 3D 吉祥物）：B 站少儿频道的做法，与工程师受众不匹配，不采用。

## 需要人工确认的点

1. 横屏字幕的黄色条是否符合你的品牌偏好（颜色在 `subtitleLandscape` 里改即可）。
2. 竖屏组件放入横屏列后偏小（约 0.5 倍）。要让画面更饱满，需要为重点组件写专门的横屏版面，这是下一阶段的工作。
